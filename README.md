# Clash-of-Clans-Raid-Automator
Small clash of clans raid automation script because i dont like playing the game

#How to use
Open up an instance of clash of clans on your desktop and be in your home base, execute the program and it will find raids and carry out attacks, repeating after the attack ends, the game must be on top to work and cannot be moved or it will break

Currently its very rudimentary, might add more features such as more humanistic input and better interaction with the game
